# Learning coverage and order

The existing course already supplied explanations for every code line. The improvement makes those explanations easier to find and follow: numbered current-line position, First line, contextual closing braces, two ordered starting lessons per stage, and a visible connection to the assignment.

Native regression coverage checks 614 generated line occurrences across seven stages and three color modes, and all 355 lines in the 20 foundation sketches. It checks both compact and detailed meanings against the generated programs. These counts describe explanation coverage, not learner completion. Unknown future block endings retain their supplied detailed text.

The first-use route starts with the image, then teaches one row and a grid before the mosaic. Existing saved contexts continue where the learner left off. Same-page stage, row/grid and Finish actions preserve the p5 practice pane. Cross-page continuation includes a save/copy reminder. Personal p5 account saving still uses the native full-tab route.

The [Week 9 class brief](https://github.com/ITPNYU/ICM-2026-Media/wiki/Homework-Mimi-07#week-9), checked through its [primary wiki source](https://raw.githubusercontent.com/wiki/ITPNYU/ICM-2026-Media/Homework-Mimi-07.md) on 2026-11-03, remains authoritative. The course leads to the silent, changing one-minute pixel piece, repeatable presentation and the learner's actual process evidence. Stage 7 reuses the Stage 6 program; its new work is collaboration, iterations, full timed viewings and documentation. The advanced project foundation remains optional practice.

Code and meaning use a native CSS size-container query when the guide itself has enough width. Narrow guides stack them. This follows the [MDN container-query documentation](https://developer.mozilla.org/en-US/docs/Web/CSS/Guides/Containment/Container_queries). No framework, rendering library or account service was added; pinned p5.js 2.3.4 remains unchanged.

Browser verification uses the native browser tools. The legacy verify-paired-lines.cjs script was inspected after correcting its directory lookup; it was not run. Native tests, browser checks and hosted asset hashes are recorded separately in the work session evidence.
