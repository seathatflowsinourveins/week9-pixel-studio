THE FIRST WORKING IMAGE IN YOUR EDITOR
Follow the Stage 1 actions in order. These are the important dependencies:

THEN: download sample.png from the workbook and save it somewhere you can find.
THEN: use the guide's Copy editor page HTML helper; replace ALL index.html

      in sketch.js, rather than adding a second setup function at its end.

If you see a missing-image error, check the project file list and quoted
filename. A computer path such as C:\Downloads\sample.png does not refer to an
uploaded editor file. The code uses "sample.png" when it is beside sketch.js.
If it is inside an assets folder, use "assets/sample.png" instead.

THE EIGHT LINES YOU ARE LEARNING
The exact current generated code appears in the workbook's line reader.

let picture;
  Reserve a name that can remember the loaded image.
async function setup() {
  Define the preparation instructions p5 calls once. Async permits waiting.
  picture = await loadImage("sample.png");
  Request the named file and wait until it is ready, then remember the image.
  createCanvas(640, 480);
  Make a drawing surface 640 pixels wide and 480 pixels tall.
  pixelDensity(1);
  Keep coordinate-to-buffer arithmetic simple: one stored pixel per unit.
  image(picture, 0, 0, width, height);
  Draw the image from the top-left corner across the canvas dimensions.
  describe("The original source image displayed across a larger canvas.");
  Provide a text description for people who cannot see the canvas.
}
  Close the setup function's group of instructions.

A SINGLE CONTROLLED CHANGE
Change createCanvas(640, 480) to createCanvas(320, 240). Run again.
The display becomes smaller. The source file is still 320 by 240 pixels.
Restore the larger canvas, run again, and save the working version.
