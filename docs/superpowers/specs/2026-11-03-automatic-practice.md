# Automatic p5 practice beside the explanation

The learner explicitly requests automation when changing phases. Keep the real official account editor and saved URL intact, but make a local editable p5 practice pane the default in editor view. It needs no account and follows the selected stage or row/grid chapter automatically. Generated guide code is the source of truth for clean drafts. Each phase has its own locally saved draft; an edited draft is restored rather than overwritten. Changed lesson settings retain an edited draft and offer Use lesson code plus Undo replacement. Typing saves locally; Run executes the draft. Copy/download exports the actual draft, with a separate copy-guide action retained for the account handoff.

Keep code and explanation beside each other. Current guide line is shown and highlighted in the practice code only while it matches the guide; clicking a matching line selects its explanation. Draft edits do not pretend to have generated explanations. A native textarea and existing pinned p5 runtime avoid new editor dependencies. Use a generic practice iframe runner, with early errors and token/source/origin-checked messages. It must not apply the lesson preview's teaching/draw wrappers to edited code.

The existing official p5 pane remains mounted behind a clearly named Account editor tab; switching phases never rewrites that account source or implies account saving. Its full-tab link still supports native login and Save. Default Practice tab shows which phase is running, an editable source, Run, Use lesson code, Undo replacement, Copy my code and Download. Distinguish local draft saving from account saving.
